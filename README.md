# 文字修仙

手机网页文字修仙放置游戏。账号登录，存档保存在服务器，离线也会继续修炼。

## 一键安装（Debian / Ubuntu）

```bash
curl -fsSL https://raw.githubusercontent.com/hyp3699/xiu/main/deploy/install.sh | sudo bash
```

装好后访问 `https://你的IP或域名/xiuxian/`

## 更新

改完代码推到 GitHub 后，在服务器上运行：

```bash
sudo xiu-update
```

会自动拉取最新代码并重启存档服务。玩家存档在 `/var/lib/xiu/xiu.db`，更新不会丢档。

## 加一个新玩法（比如炼丹）

1. 新建 `web/js/modules/liandan.js`：

```js
G.module({
  id: "liandan",
  tab: "liandan",                       // 底部标签名
  defaults: () => ({ furnace: null }),  // 存档里需要的字段（老存档会自动补上）
  tick(offline) {                       // 每 10 秒执行；离线时也会补算
    // 例如：炼丹进度 +1，满了就出丹
  },
  api: {                                 // 按钮调用：onclick="G.startLiandan()"
    startLiandan() { /* ... */ this.after(); },
  },
  view() { return `<div class="card">丹炉</div>`; },
});
```

2. 在 `index.html` 里加一行 `<script src="js/modules/liandan.js"></script>`，底部 `#tabs` 加一个按钮。

写在 `tick` 里的东西，玩家离线期间会自动继续进行。

## 规则速查

- 开局为凡人，100 修为突破为练气期一层；之后 18 个大境界 × 10 层，每层修为翻倍
- 必须学会至少一部秘诀才能修炼；每 10 秒修炼一次，1 灵气 = 1 修为；没有灵气无法修炼
- 修为满必须手动突破；大境界有成功率
- 修炼速度 = (境界基础 + 秘诀) × 灵根 × 聚灵阵倍率 × (1+丹药%) × (1+练功房%)，修炼页实时显示各项加成
- 聚灵阵：初始 0 级，每 10 秒聚灵一次（每升一级聚灵都增加）；开关只影响修炼加成，不影响聚灵
- 洞府：聚灵阵、炼丹房、炼器室、画符室、灵药园、灵兽室、洞府阵法、道童居（后 7 个待开发）
- 功法：七类（心法 防御、功诀 攻击、真经 气血、秘诀 修速、身法 命中、遁术 闪避、法诀 法力）× 黄玄地天四阶；法术：金木水火土雷 × 天地玄黄四阶；都是 12 层
  - 功法殿用贡献学习（第 1 层），之后修炼升层需要时间（3分钟 … 15小时），期间每 5 秒消耗修为；修炼队列最多 15 个
  - 功法加成为固定数值；法术伤害 = 攻击 × (100% + 30% × (星级-1)) + 固定伤害，修炼只加固定伤害；施法消耗法力
- 门派：宗门大殿（7 级职务、每日俸禄）、功法殿、事务堂（30 分钟一轮，可自动）、练功房、宝库、炼丹房、炼器室、试炼塔（100 层）、秘境
- 命中/闪避为数值：闪避几率 = (对方闪避 - 己方命中) ÷ 12 %，最高 50%
- 只有修炼页显示顶部信息和信息栏，其他页面消息以浮动提示显示
- 背包：装备（头盔 护甲 武器 腿甲 靴 吊坠 + 6 戒指）、法宝栏、法术栏（每个大境界开 1 格，最多 12 格）
- 世界：凡界 9 张地图（练气→渡劫），可历练或自动探索（每次 100 秒，显示次数，奖励直接进背包；得灵石、灵药、矿物等；探索时不能修炼；气血低于 30% 自动停止）
  仙界、魔界、冥界、神界、天外天待开放
- 境界提升：少量增加气血、攻击、防御、法力、神识；闪避、暴击不随境界增长
- 气血、法力每 10 秒恢复 1%
- 丹药只加修炼速度；某境界品质的丹药只能该境界及以下服用
- 按时间计算的功能请用 G.now()，离线补算才会正确

## 数值设置（改平衡看这里）

所有数值都集中在 **`web/js/config/numbers.js`**，分六部分：

1. 境界 & 修为：凡人→练气一层修为、每层修为倍率、大境界突破成功率
2. 人物属性：成长倍率、基础属性、命中闪避公式参数、回血比例
3. 聚灵阵：聚气基数、每级聚气倍率、修炼加成倍率、升级灵石、灵气上限
4. 怪物：强度倍率、命中/闪避成长、首领（boss）各项加强倍率
5. 历练 / 自动探索：探索时长、事件概率、灵石/药材/矿石掉落倍率、地图掉落倍率、丹药装备概率
6. 功法 & 法术：修炼时间、修炼消耗修为倍率、功法效果、星级倍率、法术伤害、学习所需帮贡
7. 灵根：最高等级、每级法术伤害/功法效果加成、升级灵石

改完把 `web/index.html` 里的 `?v=数字` 加 1，推送后服务器执行 `sudo xiu-update`。

## 自动探索

- 每次 100 秒，每秒走一步：固定 10 个小怪 + 最后 1 个首领，灵药、矿石各 5~10 次，其余无事
- 怪物掉 灵石、内丹、灵血、药材、矿石（内丹、灵血分九阶，第几张地图掉几阶），首领 ×5
- 收获先记着，100 秒结束一起放进背包；气血够三成继续下一次
- “探索信息”栏实时显示每一步发生的事
- 凡界 9 张地图掉落种类相同：9 种药材、9 种矿石、灵石；地图越高数量越多（第 9 张最多 10 倍）
- 怪物不掉丹药、装备

## 门派 & 灵根

- 每星 12 个门派，分 金木水火土雷 六属性，每属性 2 个；门派功法、法术都是该属性
- 任一门派的功法殿可学本星级全部门派的功法和法术（按阶、属性筛选）
- 功法名 = 门派前缀 + 随机词 + 后缀，四阶名字各不相同
- 灵根页：六种灵根各自升级（灵石），每级 +1% 对应属性法术伤害、+1% 对应属性功法效果，最高 3000 级
- 聚灵阵常开，1 灵石固定换 10 灵气
