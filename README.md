# 问道长生 · 文字修仙

手机网页文字修仙放置游戏。账号登录，存档保存在服务器，离线也会继续修炼。

## 一键安装（Debian / Ubuntu）

```bash
curl -fsSL https://raw.githubusercontent.com/hyp3699/xiu/main/deploy/install.sh | sudo bash
```

装好后访问 `https://你的IP或域名/xiuxian/`

## 更新

改完代码推到 GitHub 后，在服务器上运行：

```bash
sudo xiu-update
```

会自动拉取最新代码并重启存档服务。玩家存档在 `/var/lib/xiu/xiu.db`，更新不会丢档。

## 加一个新玩法（比如炼丹）

1. 新建 `web/js/modules/liandan.js`：

```js
G.module({
  id: "liandan",
  tab: "liandan",                       // 底部标签名
  defaults: () => ({ furnace: null }),  // 存档里需要的字段（老存档会自动补上）
  tick(offline) {                       // 每 10 秒执行；离线时也会补算
    // 例如：炼丹进度 +1，满了就出丹
  },
  api: {                                 // 按钮调用：onclick="G.startLiandan()"
    startLiandan() { /* ... */ this.after(); },
  },
  view() { return `<div class="card">丹炉</div>`; },
});
```

2. 在 `index.html` 里加一行 `<script src="js/modules/liandan.js"></script>`，底部 `#tabs` 加一个按钮。

写在 `tick` 里的东西，玩家离线期间会自动继续进行。

## 规则速查

- 开局为凡人，100 修为突破为练气期一层；之后 18 个大境界 × 10 层，每层修为翻倍
- 必须学会至少一部秘诀才能修炼；每 10 秒修炼一次，1 灵气 = 1 修为；没有灵气无法修炼
- 修为满必须手动突破；大境界有成功率
- 修炼速度 = (神识 + 秘诀) × 灵根 × 聚灵阵倍率 × (1+丹药%) × (1+练功房%)，修炼页实时显示各项加成
- 聚灵阵：初始 0 级，每 10 秒聚灵一次；开关只影响修炼加成，不影响聚灵
- 洞府：聚灵阵、炼丹房、炼器室、画符室、灵药园、灵兽室、洞府阵法、道童居（后 7 个待开发）
- 功法：六类 × 天地玄黄四阶；法术：金木水火土雷 × 天地玄黄四阶；都是 12 层
  - 功法殿用贡献学习（第 1 层），之后修炼升层消耗修为 + 时间（3分钟 … 15小时，有倒计时）
  - 功法加成为固定数值；法术伤害 = 攻击 × (100% + 30% × (星级-1)) + 固定伤害，修炼只加固定伤害；施法消耗法力
- 门派：宗门大殿（7 级职务、每日俸禄）、功法殿、事务堂（30 分钟一轮，可自动）、练功房、宝库、炼丹房、炼器室、试炼塔（100 层）、秘境
- 背包：装备（头盔 护甲 武器 腿甲 靴 吊坠 + 6 戒指）、法宝栏、法术栏（每个大境界开 1 格，最多 12 格）
- 世界：凡界 9 张地图（练气→渡劫），可历练或自动探索（得灵石、灵药、矿物等；探索时不能修炼；气血低于 30% 自动停止）
  仙界、魔界、冥界、神界、天外天待开放
- 境界提升：少量增加气血、攻击、防御、法力、神识；闪避、暴击不随境界增长
- 气血、法力每 10 秒恢复 1%
- 丹药只加修炼速度；某境界品质的丹药只能该境界及以下服用
- 按时间计算的功能请用 G.now()，离线补算才会正确
